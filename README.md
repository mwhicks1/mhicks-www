# Mike Hicks WWW

This repository is the source of my WWW site, rendered at [https://mhicks.me](https://mhicks.me). It is a
[Hugo static site](https://gohugo.io/), hosted on [GitHub](https://github.com), and deployed to [GitHub Pages](https://pages.github.com)
hosting, using the continuous integration available through
[GitHub Actions](https://actions.github.com). The site is uses the theme [Hugo Apéro](https://github.com/hugo-apero/hugo-apero), and started from a template developed by [Jérémie Lumbroso](https://github.com/jlumbroso) (thanks!).

Feedback welcome!
