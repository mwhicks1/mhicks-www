## About

This course covers the mathematical underpinnings of reliable software, using the _Software Foundations_ textbook series, now available as an interactive online book with executable [Lean](https://leanprover.github.io/) code embedded directly in the text. Students learn functional programming, logic, and how to construct machine-checked proofs about programs.

See the [course website](https://www.engineering.upenn.edu/~cis5000/current/index.html) for the syllabus, schedule, and other details.
